# 财报阅读（earnings-reader）

季频引擎：财报披露期手动触发，一天一句"读 X月X日的财报"。
v3 单段式（2026-11-05 用户重定流程）：纯确定性筛选入库，无 Claude 判定段、不读财报正文、不处理业绩预告。
设计与口径见 `docs/DESIGN.md`；族规约见 `../CONVENTIONS.md`。

## 流程（一条命令）

```bash
python3 scripts/pipeline.py --date 2026-10-03                # 出 final.md(不发飞书)
python3 scripts/pipeline.py --since 2026-10-28 --until 2026-10-30
python3 scripts/pipeline.py --date 2026-10-03 --publish      # 发文档+写 Base
```

1. **披露清单**：东财主源（问财备源）取窗口内正式财报披露行，报告期自动识别（任意季通用）
2. **40% 闸门**：营收/归母/扣非三指标**单季同比可算侧全>40%**；当季亏损出局；扭亏类（基数≤0）须当季归母≥0.5亿；ST/退市警示出局；环比不否决仅呈现
3. **近4季三线表**：F10 累计→单季差分，每指标 金额(亿)/同比/环比 三行 × 4 季
4. **发布**（`--publish`）：
   - 飞书文档 `《{季}报监测日报 YYYY-MM-DD(N家)》` → **「财报记录」文件夹**（对齐历史监测日报系列格式：过闸标的=摘要行+季度表, 未过闸=一句话带过）
   - 过闸标的 upsert **「重点跟踪标的」Base**（by 股票代码带后缀; 字段: 营收/归母/扣非同比%、来源报告、档位`第一档>40%`、状态`跟踪中`、首次纳入、更新日期、报告链接; 更新不覆盖 状态/首次纳入）
   - 落幂等台账（发布成功才落账, 重跑不重复）

产物 `outputs/{日期}/`: `final.md`（监测日报）、`machine.json`（结构化快照+未过闸清单）。**过闸 0 家也是正常结果**，如实报告。

## 口径速记（详规见 docs/DESIGN.md）

- 增速全部为**单季同比**（当季 vs 去年同季单季），F10 累计口径自算差分
- 幂等: (股票代码, 公告日) 台账, `--force` 忽略
- 零问财额度消耗（东财全链; 问财仅在东财清单挂掉时兜底）
- 报告页脚带"非投资建议"
