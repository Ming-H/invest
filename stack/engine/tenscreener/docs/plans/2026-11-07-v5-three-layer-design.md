# tenscreener v5.0 设计:三层望远镜判定框架(时代β·行业β·个股α·发现度·风险)

> 2026-11-07 用户定稿。核心升级:判定从"公司单筒望远镜"升级为"三层望远镜"——
> 时代β(值不值得投这个时代)×行业β(纯基本面周期时钟)×个股α(背景/属性/产能/研报)
> ×发现度(资金与机构是否已发现=左侧/右侧定位)×风险(双向证据强制)。
> v4.2 及之前的个股三线/先行/股东/价格体系全部保留,本层是其上的组织与证据升级。

## 1. 设计动机(用户三处修正)

1. **行业β剔除资金维度**——"资金不热正是机会"。行业β管"值不值得"(基本面时钟),
   资金管"是不是时候"(发现度)。两者组合出两种击球形态:
   行业β顶+个股未发现=**左侧黄金错杀**(若羽臣 24Q3/松发 2024);
   行业β顶+个股已发现=**右侧跟随**(中际旭创 2024)。拥挤=风险。
2. **时代β证据实时化**——静态清单会过时,判定必须基于当天的世界:
   政策/产业新闻实时检索 × 主线行业指数表现实时算 × 历史脉络档案仅供对照。
3. **个股α引入研报情报流**——consensus() 已拉东财研报清单(CSV 含标题/机构/评级/EPS
   预测),从"数量统计"升级为"标题流+EPS 修正序列+覆盖密度趋势",标题原样进素材包
   方便人工追踪。

## 2. 心智模型:五问漏斗(硬闸管成本,五问管判定)

```
Stage1 硬闸(不变) + 拒否卡"近期重组未并表→--force-full"提示(蜕变型已知盲区)
Stage2 素材包(每次实时采集):
  ㈠ 背景调研: 主业变更/重组/实控人/更名史(ORGINFO+主营构成跨期=最硬蜕变证据)
  ㈡ 行业素材: 基本面景气实证(板块内双线>40%公司数) + 板块指数表现
  ㈢ 研报情报流: 标题流+评级+EPS修正序列+覆盖密度(consensus 升级)
  ㈣ 个股资金面: 板块涨幅榜排名/板块共振/股东户数趋势(发现度三表盘之一)
  ㈤ 行业档案引用: 按申万行业挂载 references/industries/{行业}.md
Stage3 五问判定(verdict v3):
  Q1 时代β / Q2 行业β / Q3 个股α / Q4 发现度 / Q5 信号与风险
Stage4 条件发布(不变) + 报告"三层判定"章 + 确定性风险检测器
```

三典(静水7因子/CAN SLIM/lynch)不废弃:五问供给证据,三典仍是标尺;
核心因子#4/#7 与 lynch 六分类的判定**必须引用**五问字段,不再凭印象。

- **发现度拥挤**:discovery.phase=拥挤 → 强制警示(静水"人多的地方不要去")

## 4. 关键概念

### 4.1 发现度(新维度,全确定性,零新数据源)

| 表盘 | 指标 | 来源 |
|---|---|---|
| 资金热度 | 所属板块当日涨幅榜排名+板块指数 60/250 日 | sector.py(东财免费) |
| 机构关注 | 研报覆盖机构数趋势(3家→15家=拐点) | consensus(升级) |
| 筹码结构 | 股东户数趋势(降=集中)+十大流通股东进退 | judge 已有 |

组合:行业β×发现度 → 左侧错杀(黄金)/右侧跟随/顶部拥挤(风险)。
拥挤=研报全覆盖+全买入+户数新低+板块榜首=没有新增买家。

### 4.2 周期时钟的 lead_lag(防周期兑现段误判)

造船:订单 2021 见顶→交付利润 2025-27 兑现——三线框架看到的"爆发"处在周期后段。
行业档案必须显式写"利润兑现滞后订单 N 年",否则把周期兑现段当成成长起点。

### 4.3 纯周期 vs 成长判别(双轨)

- 量价分解:营收增速≈量增×价增,从报告拆:涨价驱动(天赐=六氟价)vs 扩产驱动(宁德=渗透率量)
- 台阶判别:"这轮周期过后公司比上轮大多少?"——每轮上台阶=成长(宁德),回原点=纯周期(煤炭)

### 4.4 档案与实时的分工原则(档案永不腐化)

档案只存**不过时的东西**:周期结构/信号字典/判定方法/历史锚点/历史十倍股。
一切"当前如何"的结论每次 judge 实时核验(政策新闻检索+板块数据+研报)。

## 5. 工程结构

```
scripts/sector.py(新): 行业板块榜(free clist)/个股所属行业/板块成分/板块指数表现/
                       行业过线聚合(growth_universe∩成分) —— 当日缓存

                  render_report 三层判定章+双检测器
references/eras/主线脉络.md: 历史四轮主线(05-07/13-15/19-21/23-)结构对照,仅供参照
references/industries/{造船,光模块,白酒,锂电,医药}.md: 六节固定模板
tests/: schema v3 / PE 幻觉 / 拥挤 / 发现度表盘 / 蜕变提示 / consensus 解析 用例
```

行业档案模板(六节):
```
# {行业}(申万: {板块名})
1. 周期档案: 类型/长度/上轮顶点/驱动因素
2. 时钟判定方法: 阶段判定的指标与检索指引(每次 judge 实时核验) + lead_lag
3. 信号字典: 该行业 什么=订单先行/什么=交付/什么=价格/什么=成本(合同负债的行业语义)
4. 政策主线: 文件锚点
5. 历史十倍股: 全部当场实测(表: 公司/窗口/倍数/口径)
6. 反方证据区: [强制维护] 见顶特征清单
```
