# 造船(船舶制造)
> 别名: 航海装备/船舶制造/造船/军工船舶 —— 行业周期档案(tenscreener v5, 2026-11-07 建档)

## 1. 周期档案(结构, 不过时)

- **类型: 强周期, 一轮约 20 年**(全球造船大周期叠加船龄更替周期≈25-30 年)
- 上轮顶: **2007-2008**(2003-2008 全球贸易扩张+中国份额起飞的双击超级周期)
- 上轮底: 2012-2020(产能过剩+贸易摩擦+疫情初期, 十年出清)
- 本轮启动: 2020-2021(疫情后集运暴利催生下单潮 + IMO 环保新规 EEXI/CII 换船周期
  + 地缘重构油轮/LNG/军船需求), **新接订单 2021 年见顶**
- 产业转移结构: 1970s 日本 → 1990s-2000s 韩国 → 2010s-2020s 中国主导(本轮份额新高)
- **lead_lag(关键): 订单→交付利润约 3-5 年**。订单 2021 顶 → 交付与利润兑现段 2024-2027。
  **三线框架看到的"业绩爆发"处在周期后段**——把兑现段误判为"成长起点"是本行业最大陷阱

## 2. 时钟判定方法(每次 judge 实时核验, 不信本页结论)

判定当前阶段, 检索并核对(证据带出处):
1. 新造船价指数(克拉克森 Newbuilding Price Index)——历史高位区? 同比仍升 or 走平?
2. 新接订单(克拉克森/中国船舶工业行业协会月度)——同比方向: 正增长=上行, 连续负增长=见顶信号
3. 手持订单排期——覆盖到哪一年(2028+ = 高可见度但边际不再改善)
4. 交付量同比——交付加速=兑现段确认
5. 检索词: "新造船价指数"、"克拉克森 新接订单"、"船舶 手持订单 交付" 近 12 个月

阶段映射: 底部启动(订单由负转正+船价回升) / 上行中(订单正增+船价升) /
**兑现段(订单见顶回落但交付与利润冲高)** / 顶部区(船价历史高位+订单连续负增+交付见顶) /
下行(量价齐落)

## 3. 信号字典(先行指标的行业语义)

| 信号 | 造船语义 | 判读 |
|---|---|---|
| 合同负债暴增 | **船东预付款**(造船合同分期预付 1-5 期) | 最强订单先行信号, 领先收入 2-4 年 |
| 在手订单排期 | 收入可见度(排到 2028+=高可见) | 但边际不再延长=顶部特征 |
| 存货大增 | 在建船舶(船台占款) | 正常扩张; 配合交付节奏看 |
| 资本开支/船坞扩建 | 产能扩张(量弹性来源) | 十倍的"量"; 但全行业同时扩产=透支周期 |
| 毛利率拐点 | 高价订单交付占比提升 | 兑现段利润弹性之源 |

## 4. 政策主线

- 海洋强国(2012 十八大以来一贯表述)/造船强国("十四五"船舶工业发展规划)
- 中国船舶集团(南北船 2019-2021 合并)——总装央企整合
- 军船+远洋装备(海洋强国装备侧)

**两轮对照教学**: 同一行业两轮周期, 总装央企(上轮)vs 民营扩产(本轮)——周期β相同,
α来源不同(上轮=份额从 0 到全球第一; 本轮=产能从 0 到 N 座船坞)。

## 6. 反方证据区(强制对照, 防追高合理化)

- 船价指数处历史高位区(高价=未来均值回归风险)
- 新接订单 2021 见顶后是否持续回落(克拉克森月度)
- 全行业扩船坞(恒力/扬子江/新时代等)——产能潮透支下一轮周期, 重复 2010-2012 过剩
- **周期顶 PE 幻觉**: 兑现段利润最漂亮、PE 最低——恰是最危险的时刻, 检测器会强制警示
- 证伪条件示例: 新接订单连续两年负增长 且 船价指数同比转负 → 周期见顶判定成立
