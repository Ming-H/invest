# 医药(疫苗/CXO/医疗器械)
> 别名: 医疗/医药/生物制品/疫苗/CXO/医疗器械 —— 行业周期档案(tenscreener v5, 2026-11-07 建档)

## 1. 周期档案

- **类型: 异质性行业——子赛道周期结构完全不同, 必须先分赛道再判周期**:
  ①疫苗: 事件渗透率(HPV/新冠疫苗=一次性渗透脉冲, 爆发快衰减也快)
  ②CXO: 全球研发投入周期(10 年长坡, 2021-2024 受生物安全法案+投融资寒冬出清)
  ③器械/耗材: 产品周期+集采政策周期(单品渗透)
  ④创新药: 审批+医保谈判+出海授权(BD)三重节奏
- 上轮大顶: 2021(吃药行情+新冠受益双顶); 集采常态化后 2022-2024 出清
- **lead_lag: 管线/批签发领先收入 1-3 年(疫苗); CXO 订单→收入 2-4 季; 创新药 BD 授权是股价即期催化**

## 2. 时钟判定方法(实时核验)

1. 子赛道先定位(标的主营: 疫苗看批签发/CXO 看订单与员工数/创新药看管线与 BD)
2. 医保谈判/集采规则边际(温和化=政策底, 2023 年来创新药支持政策转向)
3. 全球生物医药投融资(FEIR XBI 指数)——CXO/创新药的需求先行
4. 检索词: "批签发"、"CXO 订单"、"创新药 BD 出海"、"医保谈判"
- 阶段映射(按子赛道): 疫苗=事件脉冲中/后; CXO=出清尾声/订单回暖; 创新药=政策转暖+出海兑现

## 4. 政策主线

- 健康中国 2030(长期) / 集采与医保谈判(压制变量, 边际温和化) /
  创新药支持政策(2024- 转向明确支持+全链条支持文件) / 出海 BD(当代主线之一)

## 6. 反方证据区

- 事件脉冲型(疫苗/疫情受益)的"渗透率"是一次性的——英科式崩塌(逻辑可证伪)
- 集采范围扩大(器械/中药注射剂等新领域)
- CXO 地缘政治(生物安全法案变体)
- 证伪条件示例: 疫苗批签发同比连续两季下滑 → 事件脉冲结束判定成立
