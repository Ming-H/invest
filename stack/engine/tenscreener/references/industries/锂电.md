# 锂电池/新能源车产业链
> 别名: 电池/能源金属/锂电/光伏设备/电源设备 —— 行业周期档案(tenscreener v5, 2026-11-07 建档)

## 1. 周期档案

- **类型: 渗透率成长(需求)叠加资源/产能周期(供给)**——三层周期嵌套:
  ①渗透率 S 曲线(成长主导, 5-10 年) ②产能周期(各环节扩产-过剩-出清, 2-3 年)
  ③资源价格周期(碳酸锂等, 2020-2022 暴涨 10 倍后 2023-2024 暴跌 80%)
- 上轮主升: 2019-2021(EV 渗透率 5%→20% 的最陡段+全球放水); 2022-2024 出清(产能过剩+锂价崩)
- **lead_lag: 渗透率数据(月度销量)最领先; 资源价格滞后需求 1-2 季; 产能出清看"资本开支同比转负+格局出清"**
- 台阶判别的教科书: 宁德每轮周期后市占率/单位盈利上台阶(成长); 材料环节多数回原点(周期)

## 2. 时钟判定方法(实时核验)

1. EV 月度渗透率(中汽协/乘联会)——S 曲线位置: <15%最陡段 / 15-35% 主升后段 / >35% 成熟
2. 碳酸锂/六氟价格同比方向(资源周期位置)
3. 各环节产能利用率与资本开支同比(扩产潮=未来过剩; 出清=资本开支转负)
4. 检索词: "新能源 渗透率 月度"、"碳酸锂价格"、"动力电池 产能利用率"
- 阶段映射: 渗透率陡升期(戴维斯双击) / 渗透率中段+产能过剩(杀估值) / 出清尾声(布局窗) /
  资源价格反弹脉冲(交易性)

## 3. 信号字典

| 信号 | 行业语义 |
|---|---|
| 合同负债 | 车厂预付电池款——需求能见度 |
| 存货 | 材料(锂盐)库存的涨价弹性 / 电池成品的压货风险, 分环节看 |
| 资本开支 | 产能扩张(量的来源); 全环节同时暴增=过剩前兆 |
| 单位盈利(GWh 毛利) | 格局与议价力的最硬指标(宁德 vs 二线分化) |
| 资源价格 | 上游环节(锂/钴/六氟)的"价"弹性——纯周期属性最强处 |

## 6. 反方证据区

- 渗透率 >30% 后增速自然回落(S 曲线后半段, 估值中枢下移)
- 产能过剩+价格战(2023-2024 实况: 材料环节全面亏损出清)
- 技术路线迭代(固态电池/钠电)颠覆现有产能价值
- 证伪条件示例: 渗透率同比增速连续两季 <10% 且 碳酸锂同比下行 → 成长后半段+资源下行双杀
