# 白酒
> 别名: 白酒/酿酒/白酒Ⅱ —— 行业周期档案(tenscreener v5, 2026-11-07 建档)

## 1. 周期档案

- **类型: 消费成长 + 库存周期(3-4 年小周期)叠加**; 2016-2021 为消费升级长牛(机构抱团时代主线)
- 长驱动: 消费升级+高端化+集中度提升(份额向头部名酒集中)
- 小周期: 渠道库存(批价)——加库存上行 2-3 年 / 去库存下行 1-2 年
- **lead_lag: 批价(飞天茅台散瓶/普五)领先报表 2-3 季**; 渠道库存领先报表 1 年以上
- 上轮大顶: 2021-02(消费抱团瓦解); 2012-2015 曾受塑化剂+禁酒令深度调整(高端腰斩)

## 2. 时钟判定方法(实时核验)

1. 飞天茅台批价(散瓶/原箱)——绝对位与同比方向(批价上行=景气, 持续阴跌=去库存)
2. 高端酒(茅五泸)动销与回款进度(春节/中秋双节, 研报渠道调研)
3. 渠道库存月数(龙头库存 1-2 月健康, >3 月压力)
4. 检索词: "飞天 批价"、"白酒 动销"、"渠道库存 白酒"
- 阶段映射: 加库存上行(批价升+动销旺) / 顶部(批价历史高位+库存累积) /
  去库存(批价阴跌+报表仍惯性增长=最迷惑段) / 出清尾声(报表出清+批价企稳)

## 4. 政策主线

- 消费刺激政策(温和+); 消费税改革(潜在压制变量, 跟踪人大/财政部口径)
- 无强产业政策主导——**政策权重低于造船/AI, 时代β靠"消费升级叙事+机构定价权"**

## 6. 反方证据区

- 批价持续阴跌+渠道库存>3 月(报表滞后掩盖, 最迷惑)
- 人口结构(饮酒人口长期递减)——长坡但非永续
- 消费税改革落地(短期情绪+实质压制)
- 证伪条件示例: 飞天批价连续两季下行 且 龙头合同负债同比转负 → 去库存周期确认
