# 历史 10 倍股启动特征库(逆向匹配 · 方法 4)

> 静水强调"复盘历史牛股"。提炼它们**启动时**的共性,作为新候选的匹配画像。
> **所有案例仅为历史研究,非推荐;历史会重演但不会简单重复。**

## 启动特征画像(命中越多,十倍潜力越高)

| 维度 | 启动时特征 |
|---|---|
| **市值** | 小中盘起步(多数 50-300 亿;少数时代级浪潮可更大) |
| **行业** | 处于时代级高景气行业**开端**(新能源车/光伏/AI/创新药/消费升级…) |
| **催化** | 爆款新品 / 供不应求 / 政策红利 / 出海突破 |
| **业绩** | 拐点加速:从低速/亏损 → 高速增长,且增速提升 |
| **机构** | 基金持股从低位开始提升(机构刚开始介入) |
| **股价** | 突破整理 / 创一年新高 |

## A 股历史示例(研究用,非推荐)

| 股票 | 区间 | 启动逻辑 |
|---|---|---|
| 宁德时代 | 2019-2021 ~10x | 新能源车渗透率极低 + 龙头 + 业绩爆发 |
| 阳光电源 | 2020-2021 ~10x | 光伏逆变器出海 + 储能风口开端 |
| 酒鬼酒 | 2020 ~10x | 次高端白酒消费升级 + 内参放量 |
| 九安医疗 | 2021-2022 ~30x | 新冠抗原家用爆款(极致供不应求) |
| 中际旭创 | 2023-2024 | AI 算力光模块(800G)放量 |

## 启动特征 → TPS 因子映射
- 市值小 → **F3** 高分
- 高景气开端 → **F1** 行业空间高分
- 强催化 → **F5** 高分
- 业绩拐点加速 → **F4** 高分
- 机构初介入 → L2 的 I 要素加分

## 反例(看着像 10 倍但不是)
- **周期反转股**(存储/有色底翻):非持续成长,F1 行业空间实际有限
- **题材炒作股**:无业绩支撑,F4 极低
- **已被炒完完整周期的**:景气见顶,不在"开端",F1 低
- **低基数暴增**(净利+4000%):看扣非绝对规模,F4 要打折

## 用法
对 L3 Top 候选,逐项比对启动画像,命中度高的优先。但**每轮景气行业不同**,核心是找"当下"的开端行业 + 核心受益标的。
