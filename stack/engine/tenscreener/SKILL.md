# tenscreener · 十倍股单标的判定与生命周期监测

## 判定心智模型(v5.0, 2026-11-07): 五问漏斗

> 硬闸管成本,五问管判定: **Q1 时代β**(是否当代主线,实时政策×市场)→**Q2 行业β**
> (纯基本面周期时钟——资金不热正是机会,资金维度归 Q4)→**Q3 个股α**(背景蜕变/
> 纯周期vs成长/产能倍数/研报情报)→**Q4 发现度**(三表盘:左侧黄金错杀/发现中/拥挤)→
> **Q5 信号与风险**(双向证据强制+周期顶PE幻觉+证伪条件)。三典标尺不变,核心因子#4/#7
> 与 lynch 六分类必须引用五问证据。行业周期档案见 `references/industries/`(造船/光模块/
> 白酒/锂电/医药,档案只存不过时的东西),主线脉络对照见 `references/eras/主线脉络.md`。
>
> 设计全文: `docs/plans/2026-11-07-v5-three-layer-design.md`

## 定位(北极星, 2026-11-05 用户定稿)

> **判定一只给定标的: 是不是"业务体量能增长 10 倍"的超级成长股, 处于哪个阶段。**
> 只做逐只判定, 只给结论与信号; **不产出名单、不荐股、不给买卖指令**。
> 收敛到 1-2 只、买哪只, 永远是投资人的纪律(静水核心)——本技能不越位。

## 工作流(Claude 如何执行)

### judge · 单标的分级判定(v5.0 判断权威)

用户对**一个标的**问"是不是十倍股/在哪个阶段"时:

1. `python3 scripts/cli.py judge --code 603259` —— **Stage1 硬闸自动前置**: 不过闸直接输出
   ⛔ 快速否决结论卡(近4季三线表+否决原因+绕闸提示), 流程秒级终止;
   过闸则继续全免费源深读(东财F10/资产负债表/股东/主营构成/一致预期+腾讯K线+巨潮PDF,
   零问财额度), 产 `outputs/judge/{代码}_{日期}/pack.md`(判定素材包: 八季三线/先行信号/
   股东进退/报告章节原文/价格与β/跨期记分卡/算法阶段预判+判定模板)
2. **Claude 判定(Stage3)**: 读 pack.md, 结合 `../jingshui/references/财报分析框架.md`
   (核心因子7条+5不买)、`../can-slim/SKILL.md`(七要素)、`../lynch/SKILL.md`(六分类)
   写同目录 `verdict.json`(schema 见 pack.md 第九节; 校验失败走确定性兜底不阻塞);
   含 **pdf_summary**(2026-11-05 新增): 精读第七节两厚报告章节, 每份厚报告总结一段
   (景气措辞/经营要点增量/募投节奏/风险/非经常) + **『跨期对比』两厚对读找变化趋势**
   (什么表述新出现/消失、景气定调升降、募投节奏快慢、风险条目增减——与第八节 C表述漂移互证)
3. `python3 scripts/cli.py judge --code 603259 --publish` —— **条件发布(Stage4)**:
   - `is_tenbagger_candidate=true` → 校验+组装+**发布飞书全量文档**并清理本地
     (仅留 feishu_url.txt; 不保留 report.md)
   - `is_tenbagger_candidate=false` → 对话返回判定结论, 清理全部产物, 不发飞书不落盘
   - 发布文档含**近4季财务三线明细表**(环比取显示窗外第5季自算, 首季不缺)、
     **两厚报告精要与跨期对比**、及全部中间分析(每步判定依据)

**跨期趋势记分卡(v3.1, 2026-11-05)**: 素材包第八节由确定性代码(trend.py)硬算七类跨期信号并
**强制渲染**——A指引漂移(全年收入/利润指引区间跨期时间线, "由X上调至Y"期内上修也计上调;
连续上调=管理层用数字表态看多) / B股东身份(十大流通股东按 社保-汇金证金=国家队、香港中央结算=
北向、保险=险资、基金=公募 分类的时间线; **社保新进或增多=国家队入场**) / C表述漂移(上升词21个/
风险词12个 × 报告期命中矩阵) / D先行斜率(合同负债/存货/应收/capex/FCF 的 方向+加速度) /
E非经常量级趋势 / F经营净额趋势 / G三线形态。判定(verdict.trend_signals 四字段)必须逐条回应记分卡。

**PDF 归档(v3.1)**: 厚报告 PDF **归档不删**, 四级路径 `--pdf-dir`单次指定(持久为默认) >
`TENSCREENER_PDF_DIR` > `cache/config.json` > `outputs/pdf_library` 兜底; 已存在同报告跳过下载
(幂等)。首次对用户使用时若未见配置, 询问一次归档路径并带 `--pdf-dir` 跑(即成默认)。

判定输入 = 基本面序列(8季) + 报告内容(两厚PDF+薄报告API) + 价格位置 + 大盘β + v5五素材节(背景调研/行业素材实时/研报情报流/发现度表盘/行业档案挂载);
输出只给判定不给买卖指令。

### 辅助发现通道(scout/runner)与生命周期(watch/track)

给定标的判定之外, 两条**辅助**发现通道与生命周期监测(全市场扫描类, 非判定主路径):

| 级别 | 数据 | 筛什么 | 产出 |
|---|---|---|---|
| **L1 scout 问财初筛** | 问财 | **左侧错杀**(业绩已过线、股价还没看见):营收≥50% + 市值<300亿 + 近1年<30%+近3年<100%+近6月>10% + ROE>5 + 扣非为正 + 剔周期/剔距ATH≥75% + 三线序列排序加权 | 5000→十几(排序候选) |
| **L2 深度体检** | 问财补全 + cninfo财报 | CAN SLIM 七要素 + 静水清单打分(C/L/N/M 已接真实数据),标注定性缺口 | →5-10(排序) |
| **L3 十倍评估** | 研报+行业+财报 | **TPS 十倍潜力分**(七因子加权;F4 含持续性/共振) | →Top(排序非名单) |
| **runner 趋势中继** | 问财1次+腾讯K线(免额度)+zhishu | **右侧:上涨期间识别十倍股**(中际旭创型,scout 价格闸按设计挡掉的主线股):近1年>60% & 双线同比>40% & 市值<800亿 → 五阶段分类 + 板块效应 + 已涨倍数/距10x剩余 | 亮灯名单(候选) |
| **watch 右侧确认** | **全免费源**(F10三线+腾讯K线+MA250, 2026-11-07起零问财) | scouted→confirmed:**R1 持续超预期**(≥2线≥40,连续≥2季加注)+ **R2 创一年新高**(pos_1y≥0.95)+ **R3 大盘β on**;R4 连续两披露期全不过→证伪 | confirmed 池 |
| **track 退出监测** | **全免费源**(同 watch) | holding→exit_signal 告警:**E1 增速降档**/ **E2 扣非背离**/ **E3 回撤裁定**(≥40%回撤+基本面过线→"扛住";fail→exit) | 告警非指令 |

收到"找十倍股/识别正在上涨的十倍股"请求时(辅助通道):

1. **双通道扫描**(左侧+右侧各跑一次): `cli.py screen --report --archive`(scout) +
   `cli.py runner --archive`(runner)
2. **L3 定性回填**: Claude 对 Top 逐只读研报/财报, 回填 F1/F5/F6, 重算 TPS 逐只排序
   ——**收敛与取舍是投资人的决策, 工具只提供逐只评估**
3. **入 watchlist**: `watch import --from-l1 outputs/<date>/l1.json` 或 `--from-runner`
   (runner 只导入 主升期/回调击球区/强势待确认 三态)
4. **财报季跑 watch**: `cli.py watch --run`(scouted → confirmed/waiting/invalidated)
5. **人工建仓后 track**: `track promote 代码 --cost X` → `track --run` 每季复查; `track keep/close`
6. **单票复盘**: `cli.py runner backtest 300308 --beg 2024-01-01` —— 阶段时间线+首次亮灯摘要

watchlist 状态机(`outputs/watchlist.json`):

```
scouted ──confirm(自动)──► confirmed ──promote(人工)──► holding ⇄ exit_signal(自动告警)
   │                           │                           │
   └──────invalidated(自动)──► closed ◄──close(人工)───────┘   closed --reopen→ scouted
```

**纪律:脚本只自动迁移 confirm/证伪;建仓(promote)与清仓(close)永远人工执行。**

## runner 七阶段(全部静水原文出处, 详见 references/lifecycle.md)

**主升期**(创新高+连续过线+大盘on,核心α三特征齐备) / **强势待确认**(创新高+过线但缺β或streak<2) / **回调击球区**(回撤15-40%+三线≥2线过线,"等回调分仓介入"安全点) / **深调考验区**(回撤>40%但基本面在线,"扛住"持有纪律区,非新进) / **退潮**(增速跟不上)/**利润未兑现**(扭亏中,等转正)/**预告爆发**(业绩预告中枢倒推单季爆发,跟踪级)。**不恐高、不设涨幅上限**(静水"越高越安全,恐高是90%的人赚不到大钱的根源")。

**验收(2026-08-30 第7轮全市场审计)**:①双股票回放:中际旭创(首亮2024-02/2024-05→其后+1197%)、若羽臣(2024-08→+806%);②**AI+全市场审计**(1393 只候选全枚举):**83 只真实十倍股 = 77 PASS + 6 NARRATIVE + 0 MISS + 0 LATE**,框架可见集合 100% 识别;巨型案例宏和科技 68x、宏景科技 50x 均首跑 PASS;③预告接入后扭亏型大幅提前:寒武纪 2026-05→2025-01、九安 2022-11→2021-07。详见 docs/ai10x-scoreboard.md(2026-11-05 已用腾讯前复权对 10 只抽核验, 全部为真)。

## 十倍潜力分 TPS(0-100)

```
TPS = 0.30·F1行业空间 + 0.20·F2终点可达 + 0.15·F3市值衰减
    + 0.15·F4成长性 + 0.10·F5催化 + 0.05·F6生意模式 + 0.05·F7估值
```

- **F1 行业空间(30%)**:TAM/渗透率/景气开端 —— 10 倍根因,Claude 读研报定性
- **F2 终点可达(20%)**:市值×10 的行业对标(脚本算)
- **F3 市值衰减(15%)**:`100·exp(-市值/800)`,**减分不否决**(脚本算)
- **F4 成长性(15%)**:增速水平(0-60,40档=静水线)+ 加速(0-15)+ **持续性(0-15,连续过线季数,单线孤立打折)** + 利润同步(0-10)
- **F5 催化(10%)**:新品/供不求/出海/周期开端 —— Claude 定性
- **F6 生意模式(5%)**:可扩张/护城河/定价权 —— Claude 定性
- **F7 估值(5%)**:PEG 优先(增速封顶100)/PE(脚本算)

**核心设计**:大市值不被硬卡,而是被 F3 自然压低;只有 F1(空间)极高(时代级浪潮)时大市值才能靠 F1 翻盘。

## 关键规则(必须遵守)

- **三线分别看序列、单季掉线不剔除**(回放实证 003010 24Q4:营收+14%掉线但归母/扣非+133%/+135%过线,随后照涨):共振形态只作信息披露与排序权重,不加硬过滤——忠于两框架字面法则,不自行衍生苛刻条件
- **扣非/归母背离必须拆解**(静水财报分析框架:昭衍新药例,扣非+2334%里 7 亿来自实验猴)——L2 打 0 分并标"需 Claude 拆解非经营性贡献"
- **回撤≥40% 触发的是裁定,不是卖出**:基本面仍过线→"中期调整,静水纪律为扛住";基本面 fail→exit(003010 26Q1 实测:回撤49%但三线全过→warn,事后 26Q3 反弹+25%)
- **时点新高 ≠ 区间强势**:L1 用近 1 年涨幅;watch 阶段才用 pos_1y≥0.95 做"看见"确认(5不买#3)
- **严格早期价格带**:近1年<30% + 近3年<100% + 近6月>10% + 距ATH<75%,阈值均可 CLI 调
- **问财额度纪律**:全部查询经 `wencai.py` 当日缓存+计数;批量空格分隔多股票;`--max-quarterly 20` 封顶;watch/track 已零问财(全免费源),额度全部留给 L1/runner/L2
- **不荐股、不给买卖点**:只输出判定与"确认/退出信号",exit_signal 是告警不是指令
