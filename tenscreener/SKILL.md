# tenscreener · 十倍股筛选与生命周期监测

## 北极星

> **不是产出一份名单,而是逐轮收紧、收敛到 1-2 只"业务体量能增长 10 倍"的超级成长股。**(静水核心)

融合 **CAN SLIM**(盈利成长+动量确认)与**静水**(超级成长股+景气价投),按**数据获取成本分层**:便宜数据广撒网,贵数据精砸幸存者。
生命周期三阶段复刻若羽臣(003010)十倍全程复盘:**scout 错杀筛选 → watch 披露确认 → track 退出监测**。

**runner 七阶段**(全部静水原文出处,详见 references/lifecycle.md):
**主升期**(创新高+连续过线+大盘on,核心α三特征齐备) / **强势待确认**(创新高+过线但缺β或streak<2) / **回调击球区**(回撤15-40%+三线≥2线过线,"等回调分仓介入"安全点) / **深调考验区**(回撤>40%但基本面在线,"扛住"持有纪律区,非新进) / **退潮**(增速跟不上)/**利润未兑现**(扭亏中,等转正)/**预告爆发**(业绩预告中枢倒推单季爆发,静水松发式;跟踪级)。**不恐高、不设涨幅上限**(静水"越高越安全,恐高是90%的人赚不到大钱的根源")。

**runner 已验收**:①双股票回放(tests/test_runner_replay.py):若羽臣 2024-08(1.49x→+806%)、中际旭创 2024-02(预告级提前,→+1197%);②**AI+全市场十倍股全样本审计**(tests/ai10x_enumerate.py 枚举 1262 只 ∪ 手工 131 = 1393 候选):**83 只真实十倍股 = 77 PASS + 6 NARRATIVE(叙事/商品型,字面排除)+ 0 MISS + 0 LATE**,框架可见集合 100% 识别;AI 子集 46 只=43 PASS+3 NARRATIVE;巨型案例宏和科技 68x(首亮 1.52x→+4396%)、宏景科技 50x 均首跑 PASS;③预告接入后扭亏型大幅提前:寒武纪 2026-05→2025-01(+323%空间)、赛力斯 2025-05→2024-07、九安 2022-11→2021-07(+3660%)。

## 十倍潜力分 TPS(0-100)

```
TPS = 0.30·F1行业空间 + 0.20·F2终点可达 + 0.15·F3市值衰减
    + 0.15·F4成长性 + 0.10·F5催化 + 0.05·F6生意模式 + 0.05·F7估值
```

- **F1 行业空间(30%)**:TAM/渗透率/景气开端 —— 10 倍根因,Claude 读研报定性
- **F2 终点可达(20%)**:市值×10 的行业对标(脚本算)
- **F3 市值衰减(15%)**:`100·exp(-市值/800)`,**减分不否决**(脚本算)
- **F4 成长性(15%)**:增速水平(0-60,40档=静水线)+ 加速(0-15)+ **持续性(0-15,连续过线季数,单线孤立打折——若羽臣24Q4教训)** + 利润同步(0-10)
- **F5 催化(10%)**:新品/供不求/出海/周期开端 —— Claude 定性
- **F6 生意模式(5%)**:可扩张/护城河/定价权 —— Claude 定性
- **F7 估值(5%)**:PEG 优先(增速封顶100)/PE(脚本算)

**核心设计**:大市值不被硬卡,而是被 F3 自然压低;只有 F1(空间)极高(时代级浪潮)时大市值才能靠 F1 翻盘。

## 工作流(Claude 如何执行)

收到"找十倍股/超级成长股/CAN SLIM+静水选股/识别正在上涨的十倍股"请求时:

1. **双通道扫描**(左侧+右侧各跑一次):
   - `python3 scripts/cli.py screen --report --archive` —— scout 左侧错杀
   - `python3 scripts/cli.py runner --archive` —— runner 右侧趋势中继(问财≈4-8次+腾讯K线免额度)
2. **L3 定性回填**:Claude 对 Top 逐只读研报/财报,回填 F1/F5/F6,重算 TPS,收敛到 1-2 只
3. **入 watchlist**:`watch import --from-l1 outputs/<date>/l1.json` 或 `--from-runner outputs/<date>/runner.json`(runner 只导入 主升期/回调击球区/强势待确认 三态)
4. **财报季跑 watch**:`python3 scripts/cli.py watch --run`(scouted → confirmed/waiting/invalidated)
5. **人工建仓后 track**:`track promote 代码 --cost X` → `track --run` 每季财报后复查;`track keep/close`
6. **单票复盘/验收**:`python3 scripts/cli.py runner backtest 003010 --beg 2024-01-01` —— 阶段时间线+首次亮灯摘要
7. **L2 供求信号**:用 `cninfo-disclosure` skill 下 Top 的财报 PDF,读"合同负债/产能/订单/产品价格"验证静水的"供不应求"

watchlist 状态机(`outputs/watchlist.json`):

```
scouted ──confirm(自动)──► confirmed ──promote(人工)──► holding ⇄ exit_signal(自动告警)
   │                           │                           │
   └──────invalidated(自动)──► closed ◄──close(人工)───────┘   closed --reopen→ scouted
```

**纪律:脚本只自动迁移 confirm/证伪;建仓(promote)与清仓(close)永远人工执行。**

## 关键规则(必须遵守)

- **三线分别看序列、单季掉线不剔除**(若羽臣 24Q4 教训:营收+14%掉线但归母/扣非+133%/+135%过线,随后照涨):共振形态(triple/profit_led/rev_led)只作信息披露与排序权重,不加硬过滤——忠于两框架字面法则,不自行衍生苛刻条件
- **扣非/归母背离必须拆解**(静水财报分析框架:昭衍新药例,扣非+2334%里 7 亿来自实验猴)——L2 打 0 分并标"需 Claude 拆解非经营性贡献"
- **回撤≥40% 触发的是裁定,不是卖出**:基本面仍过线→"中期调整,静水纪律为扛住"(30-40% 调整常见,单票可能腰斩);基本面 fail→exit(若羽臣 26Q1 实测:回撤49%但三线全过→warn,事后 26Q3 反弹+25%,验证阈值不过拟合)
- **时点新高 ≠ 区间强势**:L1 用近 1 年涨幅(若羽臣教训);watch 阶段才用 pos_1y≥0.95 做"看见"确认(5不买#3)
- **严格早期价格带**:近1年<30% + 近3年<100% + 近6月>10% + 距ATH<75%,阈值均可 CLI 调
- **问财额度纪律**:全部查询经 `wencai.py` 当日缓存+计数(同日重跑 0 消耗);批量空格分隔多股票;`--max-quarterly 20` 封顶
- **不荐股、不给买卖点**:只输出"10 倍潜力评估"与"确认/退出信号",exit_signal 是告警不是指令
